# Khawan — Portfolio

React + Vite + Mantine.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs to dist/
```

- Profile text and social links: `src/data.js`
- Add a video: drop the `.mp4` in `src/assets/`, import it in `src/data.js` and add it to `videos`.
- Colors: `src/theme.js`
